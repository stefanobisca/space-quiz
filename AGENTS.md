# Project rules

- Keep the quiz self-contained in `index.html`; do not add a server, build step, or dependencies.
- Use plain HTML, CSS, and JavaScript, and keep the layout centered in a narrow, responsive column.
- Preserve the quiz flow, score, progress, answer feedback, and results screen when changing behavior.
- Keep dark and light system themes, readable contrast, keyboard access, visible focus, and reduced-motion support.
- Keep interactive controls semantic and feedback available to assistive technology.
- Verify changes in the integrated browser, including relevant keyboard and quiz interactions.
